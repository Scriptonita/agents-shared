# Propuestas (RFCs)

Cambios transversales a los estándares o a las skills: los que afectan a varios
proyectos o cambian una regla de oro. Las correcciones menores (erratas, enlaces,
ejemplos) van directamente en una PR.

## Proceso

1. Copia [TEMPLATE.md](TEMPLATE.md) a `proposals/AAAA-MM-DD-<titulo-corto>.md`.
2. Rellénala y abre una PR con estado `Propuesta`.
3. Se discute en la PR. Al decidir, actualiza el estado (`Aceptada` / `Rechazada`).
4. Si se acepta, en la misma PR (o en una enlazada) se cambian los estándares afectados y
   [ARCHITECTURE-INDEX.md](../ARCHITECTURE-INDEX.md).
5. Las propuestas no se borran: quedan como registro de por qué las reglas son como son.
